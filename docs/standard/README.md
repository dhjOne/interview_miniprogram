# Standard - 小程序项目标准

本目录用于沉淀 `interview_miniprogram` 的开发标准，面向日常开发、团队协作和 AI 知识库。

## 文档清单

- `PROJECT_STANDARD.md`：小程序技术栈、目录结构、模块边界、开发规范。
- `AI_KNOWLEDGE_BASE.md`：给 AI 使用的项目上下文、常见入口、约束和高频任务指引。
- `CROSS_REPOSITORY_STANDARD.md`：小程序、后台管理、后端三端协作标准。

## 使用原则

- 新功能优先遵循本目录约定，再参考局部代码风格。
- 修改公共能力前，先检查请求封装、路由封装、用户态、加密链路是否已有统一入口。
- 面向 AI 的任务描述建议引用本目录文件，减少重复解释项目背景。
